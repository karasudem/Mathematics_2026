## Question

Without expanding the determinant, compute:

A = [ 2   4   1 ]
[ 0  -3   5 ]
[ 0   0   7 ]

State the rule for an arbitrary triangular matrix and explain it using this example.

## Solution

Given:

A = [ 2   4   1 ]
[ 0  -3   5 ]
[ 0   0   7 ]

This is an upper triangular matrix.

Step 1: Apply the Triangular Matrix Rule

For a triangular matrix, the determinant is equal to the product of the diagonal entries.

The diagonal entries are:

2, -3, 7

Step 2: Calculate the Determinant

det(A) = 2 * (-3) * 7

det(A) = -6 * 7

det(A) = -42

Step 3: State the General Rule

For any triangular matrix, the determinant is the product of all diagonal entries.

This rule works because all entries below or above the main diagonal are zero.

Final Answer

det(A) = -42

The determinant of a triangular matrix is always the product of its diagonal entries.
