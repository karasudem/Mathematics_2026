Exercise 6 – Solution

Given:

A(t) = [ t  1 ]
[ 2  t ]

We need to find the values of t for which the matrix is not invertible.

Step 1: Calculate the Determinant

For a 2x2 matrix:

det(A) = (a * d) - (b * c)

Therefore:

det(A(t)) = (t * t) - (1 * 2)

det(A(t)) = t^2 - 2

Step 2: Set the Determinant Equal to Zero

A matrix is not invertible when its determinant is zero.

t^2 - 2 = 0

t^2 = 2

t = sqrt(2) or t = -sqrt(2)

Step 3: Explain the Result

For these two values of t, the determinant is zero.

Therefore, the matrix has no inverse.

For all other real values of t, the determinant is non-zero, so the matrix is invertible.

Final Answer

The matrix is not invertible when:

t = sqrt(2) or t = -sqrt(2)

This is because its determinant equals zero for these values.
