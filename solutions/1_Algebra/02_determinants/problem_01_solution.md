Exercise 1 – Solution

We need to calculate the determinants of two matrices and determine which matrix is invertible.

Step 1: Calculate the First Determinant

A = [  3  -2 ]
[  5   4 ]

For a 2x2 matrix, the determinant formula is:

det(A) = (a * d) - (b * c)

det(A) = (3 * 4) - (-2 * 5)

det(A) = 12 + 10

det(A) = 22

Step 2: Calculate the Second Determinant

B = [ 1   7 ]
[ 2  14 ]

det(B) = (1 * 14) - (7 * 2)

det(B) = 14 - 14

det(B) = 0

Step 3: Determine Which Matrix Is Invertible

A matrix is invertible if its determinant is not equal to zero.

* det(A) = 22, so A is invertible.
* det(B) = 0, so B is not invertible.

Final Answer

det(A) = 22

det(B) = 0

Matrix A is invertible because its determinant is non-zero.

Matrix B is not invertible because its determinant is zero.
