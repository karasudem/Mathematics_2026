Exercise 10 – Solution

Given:

A = [ 1  2  3 ]
[ 2  4  6 ]
[ 0  1  5 ]

We need to explain why the determinant is zero without calculating it fully.

Step 1: Examine the Rows

The first row is:

R1 = [ 1  2  3 ]

The second row is:

R2 = [ 2  4  6 ]

We can see that:

R2 = 2 * R1

The second row is exactly twice the first row.

Step 2: Explain Linear Dependence

Since one row is a multiple of another row, the rows are linearly dependent.

A matrix with linearly dependent rows has a determinant equal to zero.

Therefore:

det(A) = 0

Step 3: Explain Noninvertibility

A square matrix is invertible only if its determinant is non-zero.

Since det(A) = 0, matrix A is not invertible.

Final Answer

R2 = 2 * R1

The rows are linearly dependent.

Therefore:

det(A) = 0

Matrix A is not invertible because its determinant is zero.
